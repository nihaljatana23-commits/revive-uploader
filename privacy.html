Privacy Policy

Revive Uploader · Last updated 24 November 2026

Revive Uploader ("the app") is a private tool that the owner of the Revive in Motion YouTube channel runs on their own computer to publish videos to that channel. This policy explains what Google user data the app accesses and what it does with it.

Who uses the app

Only the channel owner signs in to the app, and only to manage the owner's own YouTube channel. The app does not collect data from viewers or from any other person.

Google data the app accesses

  • YouTube upload and management (youtube.upload, youtube): to upload the owner's videos, set titles, descriptions, tags and thumbnails, and confirm that uploads go to the Revive in Motion channel.
  • YouTube Analytics, read-only (yt-analytics.readonly): to read view counts for the channel's own videos.

How the data is used

The data is used only to perform the actions above, for the owner. It is not used for advertising, not sold, not shared with third parties, and not used to train AI models. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The sign-in token Google issues is stored only on the owner's computer, in a file readable only by the owner's user account. The app has no server and keeps no copy of Google data anywhere else. View counts are saved in a local file on the same computer.

Removing access

The owner can revoke the app's access at any time at myaccount.google.com/permissions and delete the local token file. Doing so stops all access immediately.

Changes

If what the app accesses changes, this page will be updated and the date above changed.
