Revive Uploader

A private publishing tool for the Revive in Motion YouTube channel.

What it does

Revive Uploader is a small script that runs on the channel owner's own computer. When a new Revive in Motion Short is finished, it uses the YouTube Data API to:

  • upload the finished video file to the Revive in Motion channel,
  • set its title, description, tags and thumbnail, and
  • read view counts for the channel's own videos, so the owner can see which topics perform well.

It is used only by the channel owner, for the owner's own channel. It is not offered to other users.
